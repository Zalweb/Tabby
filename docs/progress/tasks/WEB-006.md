## Scope and acceptance

The landing, Privacy and Terms pages fit a 320px phone without horizontal overflow and retain a readable, accessible download action. Check wide phones, tablets and desktop and preserve the current release targets.

## Implemented

The responsive legal header removes the unused desktop navigation wrapper at the existing narrow breakpoint, leaving space for its download action. The landing hero frame is slightly narrower at the existing smallest breakpoint so its rotation fits. Both style mirrors contain the same CSS.

## Remaining and unverified

Native mobile-browser screen-reader behavior remains outside this layout check.

## Verification results

Existing public Android and iOS downloads return HTTP 200 and match the release hashes. Initial live issues reproduced at 320px. The scoped local browser rerun shows zero document overflow for all three routes at 320px, 390px, 800px and 1440px. The web regression suite passed. See [verification](../../verification/VER-WEB-006-DOWNLOAD-LAYOUT.md).

## Deployment

Production serves the reviewed CSS from commit `42f61ef3f1dd567df1e7248d0a03fe6a8e800670`. All three live routes fit all four tested viewport widths. [Production site](https://tabby-web-fawn.vercel.app/#download).
