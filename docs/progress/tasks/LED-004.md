## Scope and acceptance

[Audit finding](../../audits/2026-10-31-android-review.md#aud-20261031-004). Primary owner role: Data/sync agent.

- Problem: Failed operations can continuously retry.
- Impact: Permanent rejection can consume battery and repeat backend calls.
- Implement: Remove recursive refresh/replay triggering; classify failures and back off bounded transient retries.
- Acceptance: Permanent failures become needsAttention; retry count does not grow while idle; transient retries are delayed.
- Starting point: [source](../../../lib/features/tabs/application/tabby_providers.dart).
