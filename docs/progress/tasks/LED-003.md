## Scope and acceptance

[Audit finding](../../audits/2026-10-31-android-review.md#aud-20261031-003). Primary owner role: Data/sync agent.

- Problem: Retries can duplicate server writes.
- Impact: A committed write with a lost response may be inserted again.
- Implement: Add stable operation IDs to versioned RPCs and server uniqueness; route immediate and replay writes through one executor.
- Acceptance: Drop the response after commit and retry concurrently; exactly one expense/payment exists.
- Starting point: [source](../../../lib/features/tabs/application/tabby_providers.dart).
