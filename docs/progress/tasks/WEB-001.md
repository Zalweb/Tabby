## Scope and acceptance

Refresh the public Tabby landing page so it reflects the current warm app and current release, using `https://www.tarsi.cloud/` only as a structural and visual reference. The page must not invent reviews, user counts, awards, press coverage, ratings, or unrelated product claims.

Accepted outcomes:

- Tarsi-like structure: sticky header, hero with inline title pill, rotated phone, floating mascot, three feature cards, screenshot marquee, stats and principles, offline walkthrough, Q&A cards, dark download/release card, community card and dark footer.
- Authentic Tabby copy only: friendship-first running tabs, integer-centavo custom splits, GCash/Maya/QR Ph settlement with recipient confirmation, append-only ledger, offline-durable queue, reminders, group tabs, encrypted payment details, and no money held or moved by Tabby.
- Current mascot artwork and current app screenshots; no emoji and no user-facing “GitHub” link text.
- Download engine keeps release-aware APK/IPA links, version/date/size/status/changelog data roles, canonical fallbacks, escaping and cache behavior.
- `landing/` and `docs/` remain byte-identical for pages and shared assets; legal pages keep their layout and current branding.
- Responsive layout has no horizontal overflow, navigation remains usable, FAQ/release disclosures work natively, and release notes render as safe HTML.
