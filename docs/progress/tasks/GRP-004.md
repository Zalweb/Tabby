## Scope and acceptance

[Audit finding](../../audits/2026-10-31-android-review.md#aud-20261031-010). Primary owner role: Ledger/UI agent.

- Problem: Group creation is partially committed.
- Impact: Membership failure leaves incomplete group/tab records.
- Implement: Create group, members, tab and tab memberships in one authenticated transaction.
- Acceptance: Inject failure at each step; no partial group remains and a retry creates one complete group.
- Starting point: [source](../../../lib/features/tabs/data/supabase_tabby_repository.dart).
