## Scope and acceptance

- Problem: Audited corrections and cancellation.
- Impact: Users need a safe way to fix incorrect money records before M1 release.
- Implement: Add reasoned append-only correction/cancellation events, counterpart visibility and confirmation for changes to acknowledged shared obligations; original records remain.
- Acceptance: Wrong expense can be corrected without deletion; each party sees the revision and balances replay exactly.
- Starting point: [source](../../../lib/features/tabs/domain/models.dart).
