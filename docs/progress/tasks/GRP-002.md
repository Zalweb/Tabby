## Scope and acceptance

[Audit finding](../../audits/2026-10-31-android-review.md#aud-20261031-008). Primary owner role: Ledger/UI agent.

- Problem: Group shares and payer selection are incomplete.
- Impact: Existing-group defaults and aggregate counterpart shares produce wrong allocations.
- Implement: Use actual member count, explicit payer selection and individual shares throughout UI/RPC.
- Acceptance: Three/five-member odd-cent bills calculate correctly for each possible payer and perspective.
- Starting point: [source](../../../lib/features/tabs/presentation/add_expense_modal.dart).

## Implemented

Current result (2026-10-31T14:14:34.193Z): Groups retain actual registered member rosters and immutable per-member expense shares through model/parse/cache. One deterministic ID-ordered allocator preserves odd centavos for every payer/viewer. Existing groups derive member count from roster; missing/invalid rosters and group IDs as payer are rejected. New/existing group forms select the actual payer and preview every share; expense details list individual shares. Full group obligation explicitly splits among others with payer share zero.
