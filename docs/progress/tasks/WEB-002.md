## Scope and acceptance

1. Reduce public copy to core benefits, authentic app screens, download choices and essential install/legal links. Keep the existing warm branding and preserve legal pages.
2. Use latest published assets per platform and make successful, exact-artifact-approved production builds publish both downloads through a single automated workflow.
3. Verify mirrors, browser layout, asset fallback, workflow provenance and release-gate preservation. Deploy the verified website through its existing Vercel main-branch integration.

## Implemented

The revised landing page focuses on a short introduction, three benefits, actual app screenshots and the Android and iOS download choices. It removes live status, build metadata, the changelog, decorative numbering and duplicate copy. The existing feature mascot animations are integrated into the shorter page. Sideloadly instructions and the Privacy and Terms policies remain available.

Both download links track stable GitHub release assets, including with JavaScript disabled. The release automation checks matching signed Android and unsigned iOS artifacts from a trusted main run and uses the existing exact-artifact and reviewer gates. On approval, it uploads the pair to a draft, compares the real asset hashes and then promotes the full pair. The main iOS build uses the shared app version and generates source evidence from its exact Git checkout. The reviewed production iOS public-client pin is aligned with prior successful production build 44274221017.
