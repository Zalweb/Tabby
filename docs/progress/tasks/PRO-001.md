## Scope and acceptance

[Audit finding](../../audits/2026-10-31-android-review.md#aud-20261031-037). Primary owner role: Profile agent.

- Problem: Profile writes can report false success.
- Impact: Local-only email and separate wallet fields mislead users.
- Implement: Await profile persistence, verify auth email changes, and route all payment edits through saved methods.
- Acceptance: Server rejection preserves form; email changes only after verification; payment methods remain consistent.
- Starting point: [source](../../../lib/features/tabs/application/tabby_providers.dart).
