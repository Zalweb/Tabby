## Scope and acceptance

Add three continuous text rows directly below the illustrated What's inside cards and before the screenshot gallery. Use the six existing Why Tabby principle titles from the user's second reference. Keep their detailed descriptions in the existing cards. The outer rows move left and the center row moves right. Faster vertical scrolling in either direction briefly increases horizontal speed, which eases back to the idle pace when scrolling stops. The loop wraps without a visible seam, and rows fit narrow and wide viewports. The rows run automatically without a pause or resume control, as requested. Show a static layout for reduced motion or unavailable animation scripts.

Implementation plan: add the static rows to both HTML mirrors, enhance the rows using GSAP with ScrollTrigger and viewport-aware transforms, pair with scoped CSS, extend focused web verification, review, then deploy via the existing Git-to-Vercel integration.

## Implemented

Added the three warm-toned text bands and static fallback to the two landing mirrors. GSAP ScrollTrigger supplies absolute scroll velocity. A single animation-frame loop advances the three wrapped tracks with a smooth boost and recovery. A viewport observer starts and stops the frame loop, including after a fast scroll jump during page startup.

## Remaining and unverified

Firefox, Safari and physical mobile browsers are unverified. Chromium verification covers desktop and mobile viewport sizes. Production deployment and browser verification are complete.

## Verification results

The Node web suite passed. Headless Brave at 1440 and 390 pixels passed automatic direction, velocity boost for both wheel directions, runtime reduced-motion changes, and absence of a pause/resume control. The marquee fits 320, 390, 1440 and 2560 pixels and has enough copies for seamless wraps after resizing. An accelerated browser fixture crossed 7, 7 and 10 loop boundaries with zero gaps. Reduced motion, blocked GSAP and disabled JavaScript all rendered six static titles. The existing hero exceeds the 320px viewport by one pixel. The existing header can overflow at 390px when JavaScript is disabled, while the marquee fits.
