## Scope and acceptance

[Audit finding](../../audits/2026-10-31-android-review.md#aud-20261031-039). Primary owner role: Profile agent.

- Problem: Friend and group actions overstate persistence/deletion.
- Impact: Edits disappear and backend removal failures are hidden.
- Implement: Persist private nicknames, await unfriend/archive results, label archive accurately and support restore.
- Acceptance: Failure remains visible; archive restores; unfriending preserves tabs and financial records.
- Starting point: [source](../../../lib/features/connections/presentation/connections_screen.dart).

## Implemented

Current result (2026-11-01T13:05:38.561Z): Connections now persist private nicknames through an owner-bound revisioned RPC; the editor removes local-only phone/email/wallet edits and preserves a failed nickname draft. Labels are explicitly limited to the caller's Connections view, leaving canonical profile names/receiving details intact. Group archive/restore is a caller-only view preference with an archived-list toggle; shared tab status, ledger, outstanding balances and reminders stay available. Confirmation remains open on failure and closes only after acknowledgment. Unfriend awaits its persisted result, retains financial/group records and rejects obsolete results; in-flight older friend-list reads cannot resurrect the removed social state. Connection overlays close once on actor/session changes. Server operation replay and expected revisions protect retries and competing devices; core profile v2/social writes validate an explicit initiating owner. Direct shared archival is rejected.
