## Scope and acceptance

Visitors select Home, Tab details or Dark mode and see the existing screenshot and its caption. Crossfade only on interaction, support keyboard and reduced motion, keep a static fallback, and deploy the scoped update to production.

## Implemented

Home, Tab details and Dark mode now switch between existing screenshot previews with a crossfade. The gallery supports keyboard navigation and direct reduced-motion switching. The static figures and captions are available without JavaScript.

## Remaining and unverified

Production delivery is verified. Non-Chromium browser acceptance is pending. WEB-001 remains an open dependency.
